## Подсказки для выбора

- atomic, ACID, гонки, блокировки, Idempotency-Key и N+1 → тема 08.
- event loop, TaskGroup, отмена, I/O и конкурентный HTTP → тема 14.
- повторная доставка, outbox, ack, Celery и RabbitMQ → тема 17.
- метрики, логи, tracing, SLO и алерт → тема 22.
- state, plan, apply и drift → тема 24.
- probes, Pod, readiness, liveness и PVC → тема 27.
- Общий термин с несколькими значениями уточнять по вопросу: «состояние» может означать статус заказа, Terraform state или данные stateful-сервиса.
- Номера 31 и выше отсутствуют. Обозначения Ф1–Ф6 относятся к отдельному набору факультативов.
