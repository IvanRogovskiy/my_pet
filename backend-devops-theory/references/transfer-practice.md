# Перенос в новую ситуацию

Предлагать после самостоятельного успеха по предпосылке, в рамках существующей очереди повторения: максимум одно короткое упражнение за урок. Это дополнительная диагностика понимания; отказ не отменяет принятую практику и не блокирует новую тему. Не требовать знания будущих частей. При явной просьбе ученика разобрать пример можно раньше, обозначив нужную предпосылку.

| ID | После части | Новая ситуация | Что предъявить |
| --- | --- | --- | --- |
| TR01 | 07/2 | Доступ к заметкам команды вместо заказов | Решение о доступе, доверенный источник права и три проверки |
| TR02 | 08/2 | Два бронирования по два места из трёх | Расписание операций, допустимый итог и план PostgreSQL-проверки |
| TR03 | 08/3 | Повтор создания задания экспорта для организаций | Итоги точного повтора, другого тела и другого владельца; проверка числа эффектов |
| TR04 | 17/3 | Повтор события после отправки письма | Граница подтверждения обработки и ограничение внешнего эффекта |
| TR05 | 25/2 | Повтор конфигурации сборщика логов | Сравнение заявленного changed с наблюдаемыми состояниями |
| TR06 | 29/3 | Backup журнала заявок | Оценка доступной точки восстановления и план проверки restore |

Выдать только выбранное условие из [экспортёра упражнений](../assets/teaching-benchmark/README.md). Авторские критерии не показывать до самостоятельной попытки. Изменённый контекст должен требовать объяснения причины; замена только чисел не доказывает перенос.

Проверять отдельно: вывод, объяснение механизма, предложенное доказательство. Зафиксировать дословный ответ и наличие подсказок. Уместные статусы: «самостоятельно объяснил новый случай», «ответил с подсказкой», «вывод верен, объяснение неполное», «требуется повторение». Если предложен только план запуска, фактический runtime остаётся непроверенным. Не присваивать освоение всей темы по одному ответу.

После ошибки разобрать конкретную причину, затем на подходящем занятии предложить другой вариант. При повторе не показывать прежний ответ первым. Отсроченное упражнение предлагать в следующем согласованном обращении, без автоматического напоминания. Ответ агента хранить только как симуляцию, вне настоящего learning/.
