# Подробные материалы сложных механизмов

Это проверяемые опорные материалы внутри существующего курса. Преподаватель выбирает нужный фрагмент по текущей части, адаптирует объяснение и даёт самостоятельное задание. Наличие файла не означает выдачу теории ученику. Материалы не заменяют остальные части темы и не вводят отдельный подготовительный проект.

| [Outbox и эффект](17-outbox.md) | 17/2–3 | `mechanisms.py outbox`; реальный брокер отдельно |
