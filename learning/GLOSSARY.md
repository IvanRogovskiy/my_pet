# Словарь курса

Это справочник. Наличие определения не означает, что пользователь продемонстрировал понимание; такие наблюдения хранятся отдельно.

## Linux и запуск приложения

**Программа** — инструкции, которые можно выполнить; например, исполняемый файл Python и код приложения. Одна программа может иметь несколько запущенных экземпляров.

**Процесс** — выполняющийся экземпляр программы с собственным идентификатором PID и состоянием. «Программа» и «процесс» связаны, но это разные понятия. [Источник](https://man7.org/linux/man-pages/man7/credentials.7.html).

**PID** — идентификатор процесса. Повторный запуск программы может получить другой PID.

**Служба systemd** — управляемая systemd единица запуска типа `.service`. Описывает запуск программы и управление её жизненным циклом; может завершаться после работы. «Сервис» используется как синоним службы только в этом контексте; бизнес-сервис доставки — другое понятие. [Источник](https://github.com/systemd/systemd/blob/main/man/systemd.service.xml).

**Пользователь ОС** — учётная запись, с правами которой процесс обращается к ресурсам. Пользователь приложения — запись в продукте; она сама по себе не определяет пользователя процесса ОС.

**Право `r` у файла** — разрешение читать его содержимое для выбранного класса доступа.

**Право `x` у каталога** — разрешение прохода через каталог при обращении по пути. Для открытия файла нужны подходящие права на файл и проход через родительские каталоги. Это не то же самое, что просмотр списка имён (`r` у каталога). [Источник](https://man7.org/linux/man-pages/man7/path_resolution.7.html).

## Неоднозначности

- Проверка приложения от `root` не подтверждает его доступ от обычного пользователя службы.
- `systemctl` относится к среде с systemd; macOS использует другой менеджер служб.
