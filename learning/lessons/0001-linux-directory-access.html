02 / Linux · короткий шаг

Почему файл доступен, а открыть его нельзя?

Найди препятствие на пути к конфигурации OrderFlow. Учебная симуляция: команды не запускаются, права машины не меняются.

Автопроверка отключена. Прочитайте задания и отправьте ответы с объяснением в чат.

Доступ проверяется по всему пути

Чтобы открыть известный файл, процесс должен пройти через каждый родительский каталог. Право x у каталога разрешает такой проход; r позволяет читать список имён. У самого файла право r разрешает чтение содержимого.

Ниже обычный пользователь orderflow, без прав root, ACL и дополнительных привилегий. Проверяем только обычные права доступа; другие ограничения системы исключены условием.

Успешное чтение от root не доказывает, что файл откроет процесс приложения.

01 · Право прохода

Путь к файлу уже известен. Нужно пройти через его родительский каталог.

Не путай просмотр списка имён с проходом по пути. Для прохода нужно x.

02 · Найди препятствие

Процесс работает от orderflow и не входит в группу root. Все компоненты пути — обычные каталоги и файл, без символьных ссылок.

Условные права в учебном примере
ПутьВладелец:группаПрава
/root:root755
/srvroot:root755
/srv/orderflowroot:root700
/srv/orderflow/config.iniorderflow:orderflow640

Три цифры задают права владельца, группы и остальных: r = 4, w = 2, x = 1. Например, 7 = rwx, 5 = r-x.

Проверяй каталоги от корня. У /srv/orderflow права остальных равны 0; до файла процесс не дойдёт.

03 · Изменённое условие

Теперь каталог /srv/orderflow принадлежит root:orderflow с правами 740. Процесс входит в группу orderflow. Оставь владельцу rwx, дай группе чтение списка и проход, остальным — никаких прав.

Для группы сложи r (4) и x (1). Права владельца и остальных менять не нужно.
