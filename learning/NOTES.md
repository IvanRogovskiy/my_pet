# Предпочтения и условия обучения

## Подача

- Объяснять по-русски. Основание: язык учебного разговора.
- Если результат — файл, прямо называть его формат, имя, расположение и содержимое. Основание: пользователь попросил заменить расплывчатое «составь короткую заметку» конкретным действием.
- При выборе объекта объяснять, как получить список вариантов и какой вариант подходит. Основание: повторные уточнения о выборе существующей службы.
- Не считать эти уточнения доказательством отсутствия других знаний.

## Опыт

- Основы Python заявлены в контексте курса; практическая проверка этого опыта в данном разговоре не проводилась. Не повторять основы без просьбы.

## Окружение

- Локальная среда проекта — macOS на ARM; основание: исследованное окружение выполнения.
- Наличие у ученика учебной Linux VM и systemd не подтверждено. Наличие терминала macOS не подтверждает наличие Linux.
- GitHub CLI и окружение валидатора — инструменты работы с проектом, а не выполненная практика ученика.

## Хранение

- Учебные материалы и прогресс хранить в Git вместе с проектом; выбор пользователя при согласовании плана внедрения.
- Не сохранять токены, ключи и секреты. Не переносить в эти записи характеристики вымышленных проверочных стендов.
