## Что осталось для эмпирического результата

Запрошено явное разрешение на отдельные контексты для RS и реальные ответы преподавателя для HS. Ответ на запрос в этой сессии не получен; дополнительные агенты не запускались. Это ограничение правил сессии, а не требование нового skill. Готовые изолированные выдачи и их хеши перечислены в verification.json, без заготовленных «правильных ответов» рядом с выдачей.

После разрешения передать RS01–RS03 в три разных новых контекста, по одному каталогу, без истории и авторских рубрик. HS01–HS03 дать проверяющему без ожидаемых ответов. Сохранить реальные response, execution, session и снимки состояния; затем выполнить check и отдельную смысловую оценку. Не исправлять первый ответ задним числом. Если исходный временный каталог удалён, заново экспортировать комплект и зафиксировать новые хеши профиля.

Проверка деклараций fresh_context/ID не подтверждает техническую изоляцию сама по себе. Структурированное состояние не доказывает смысл текста. Набор RS начинает с авторских синтетических checkpoints: отдельно проверяется восстановление, а не качество записи состояния в предшествовавшем живом разговоре. Внешняя оценка связана с полным ответом через SHA256 и показывает непроверенные критерии. Из этих технических тестов нельзя выводить устойчивость преподавателя или учебный эффект для человека.
