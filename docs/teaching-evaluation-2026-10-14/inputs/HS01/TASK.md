# HS01: hints

Используй только файлы этой выдачи. Не читай исходный репозиторий, авторские рубрики или прошлые ответы.
Сохрани дословный ответ отдельно от выдачи. Не изменяй входные файлы.
Запиши среду, выполненные команды и фактические результаты в execution; для чтения кода укажи static_only.
Формат записи: benchmark_version, case_id, input_sha256 (хеш manifest.json в каноническом JSON),
prompt (точный текст без добавленного завершающего перевода строки), response, execution (непустые строки),
session: {id, name, date, kind: human/model/self_review, fresh_context: boolean, history_messages: integer}.
Для resume нужен отдельный новый контекст, fresh_context=true, history_messages=0; прошлую переписку не передавать.
Для resume дополнительно recovered: {part, practice, issues: {ID: open/closed/withdrawn}, next_step};
snapshot: {PROGRESS.md: полный текст после ответа, NOTES.md: полный текст после ответа}.
Для hints ответь как преподаватель по TEACHER.md; не выдавай решение без просьбы.
Для transfer ответь как ученик, без подсказок; ответ агента обязательно обозначь симуляцией.
Пути ссылок в TEACHER.md указывают на исходные материалы; отсутствующие здесь файлы не открывай.
Никакие облачные/сетевые ресурсы не требуются. Новые агенты запускаются только по разрешению сессии.
