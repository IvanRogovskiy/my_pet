# AD01 — тема 08/3

C1: enqueue(jobs, tenant, token, payload) работает последовательно в памяти. Область повтора — (tenant,token). payload — dict[str,list[int]]. Точный повтор возвращает равный результат без новой записи, изменённое тело в той же области даёт ValueError. Другой tenant независим. Изменение входных списков после вызова не должно менять сохранённое тело. Входные payload нельзя менять. Результат содержит уникальный id и снимок payload. Мутация возвращённого результата вызывающим кодом не входит в контракт.
