# AD03 — тема 08/1

C1: allocate(stock, requests) работает последовательно в памяти. stock — dict[str,int>=0], requests — list[tuple[str,int>0]], все SKU существуют. Повторяющиеся SKU нужно суммировать. При нехватке ValueError и stock неизменен; при успехе списать весь пакет и вернуть stock. requests должен оставаться неизменным даже при отказе. Конкуренция/БД здесь не требуются.
