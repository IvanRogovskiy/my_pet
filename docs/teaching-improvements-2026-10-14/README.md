## Фактический прогон после разрешения

После явного «разрешаю» проведены RS01–RS03 и HS01–HS03 в шести отдельных контекстах без родительской истории. Сохранены первые ответы, методы и полные снимки состояния; исходные ответы не переписывались. [Отчёт прогона](../teaching-evaluation-2026-10-14/README.md) содержит 23 подтверждённых смысловых критерия и один неподтверждённый, с указанием координатора-модели как оценщика.

Исходный формат не прошёл check в 6/6 случаях: execution представлен списком вместо строки. Отдельно обнаружено, что для practice оценщик требует буквальную метку, не объявленную явно в выдаче. Эти отказы не подменены успешными баллами. Для оценки исходного текста исправлена связка assessment-template/check; две новые регрессии и полный целевой набор 14/14 прошли. Первые ответы и их SHA256 сохранены.

Условия первоначальной подготовки находятся в pre-run-verification.json нового отчёта. source_sha256 в этом файле verification.json относится к подготовленной редакции; изменения оценщика после прогона отражены отдельно. TR-упражнения с человеком, RV20 и сравнение HC12 по-прежнему не проведены. Шесть синтетических сценариев с настоящими ответами модели не доказывают учебный эффект для человека или устойчивость всех будущих сессий.
