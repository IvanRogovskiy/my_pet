# Проверка учебного пространства

Дата: 2026-10-01. Тема 02, часть 1: процессы, службы и права каталогов.

## Что проверено

Временная копия `learning/` и вымышленная сдача использовались для ручного прогона текущим агентом. Это проверка применения инструкций, без независимого оценщика и без доказательства качества обучения реального человека.

| Сценарий | Результат ручного прогона |
| --- | --- |
| Продолжение из сохранённого состояния | Восстановлена тема 02/1; несданная практика не принята автоматически |
| Только macOS, Linux VM отсутствует | Выбран явно обозначенный учебный разбор; команды systemctl не запускались |
| Верная буква, неверное объяснение r/x | Ошибка объяснения отмечена, понимание не подтверждено совпадением буквы |
| Читаемый файл за недоступным каталогом | В ревью найдено препятствие в родительском каталоге |
| Предложение chmod 777 | Сопоставлено с объявленным условием; лишние права не приняты |
| Исправление после подсказки | Отдельная запись с происхождением ответа; самостоятельность не приписана |
| Верный ответ на изменённый пример, затем новая ошибка | История сохранена; прежняя запись помечена «требует повторения», очередь обновлена |
| Просьба перейти к части 2 без повторения | Выбор принят; долг по практике и очередь сохранены; часть 2 не отмечена выданной |
| Повторное чтение файлов состояния | Восстановлены следующий шаг, непроверенная практика и потребность в повторении |
| Словарь, предпочтения и источники | Использованы для объяснения; наличие справочника не превратилось в запись об усвоении |

## Проверка HTML в Chrome

Использованы установленный Chrome и временный профиль через Playwright Core 1.40.1, совместимый с локальным Node 16. Встроенный Browser не подключился: ошибка `missing field sandboxPolicy` возникла до выполнения команд браузера.

Пройдены проверки: пустой ответ, неверный ответ, подсказка, повторная попытка, сохранение признака подсказки после очистки, три правильных ответа, Enter/Tab и видимый фокус, загрузка общих CSS/JS, сброс истории после перезагрузки, отключённый JavaScript. Ошибок JavaScript нет; браузер обращался только к локальным файлам методом GET. PROGRESS не изменился.

Просмотрены desktop и мобильные снимки; на ширине 390 px нет горизонтального переполнения страницы. Длинный мобильный скриншот имел артефакт повторения кадров, поэтому вид проверен отдельными снимками видимой области.

## Исправления по результатам проверки

- Уточнено, что короткий учебный шаг не обязан воспроизводить структуру полной лекции с несколькими примерами.
- Персональное разрешение на хранение в Git оставлено в данных проекта; переиспользуемые инструкции читают выбранное хранилище.
- Пояснение об отключённой автопроверке теперь видно по умолчанию и скрывается скриптом после запуска. Проверка с отключённым JavaScript прошла после этого исправления.
