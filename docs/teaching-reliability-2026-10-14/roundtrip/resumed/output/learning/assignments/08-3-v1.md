# Практика 08/3, версия v1
C1: submit(state,buyer,key,payload) создаёт результат в области (buyer,key); другой buyer независим. C2: повтор того же тела возвращает прежний результат без новой записи; другое тело с прежним buyer/key вызывает ValueError. payload — dict со скалярными JSON-значениями, изменение внешних аргументов после вызова не проверяется. state — dict в памяти; PostgreSQL не входит в приёмку этой локальной функции.
