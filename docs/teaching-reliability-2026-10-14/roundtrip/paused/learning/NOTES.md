# Условия и предпочтения

- Исполнитель: синтетический ученик отдельного временного проекта; записи не характеризуют настоящего пользователя.
- Язык общения: русский, по prompt.txt.
- Основы Python: заявленный опыт из prompt.txt, не проверенный навык.
- Формат помощи: одна подсказка за раз; готовое решение не запрошено (prompt.txt).
- Маршрут: полный 30 тем / 92 части, явно выбран в prompt.txt.
- Сохранение: локальное learning/ этого проекта, без commit/push, по явному разрешению prompt.txt.
- PostgreSQL и Docker недоступны по заявлению ученика и не входят в критерии локальной функции. Это не ошибка сдачи.
- Среда собственного запуска преподавателя: Python 3.12.3, macOS 26.6.2, 2026-10-14. Это сведения о среде проверки, а не установленное окружение ученика.
