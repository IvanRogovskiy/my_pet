# Конфликт тела остаётся после частичной правки

Тема: 08/3.
Статус: требует повторения.
Основание: повторное ревью той же незакрытой части задания, а не новая самостоятельная попытка решения R2.
Доказательство: [частичная правка](../submissions/08-3-v1-revision1.py), строки 3–4; [собственный запуск преподавателя 2026-10-14, ход 2](../evidence/method-turn2.md), C2 different body conflict — FAIL. Предыдущее наблюдение: [0002](0002-body-conflict.md). R2 сохраняет прежний ID.

После исправления области ключа изменённое тело в той же области всё ещё возвращает предыдущий результат вместо ValueError. Сохранено наблюдение о непройденном критерии; причины понимания ученика без его объяснения не установлены. В этом ходе дана одна подсказка: сравнить сохранённое и новое тело перед возвратом найденного результата. Следующая самостоятельная правка ещё не получена; ответ после подсказки не считать самостоятельным переносом без помощи.
