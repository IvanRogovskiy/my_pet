# HC05 — тема 06/1

C1: cents(raw) принимает строку с конечным десятичным числом рублей >=0, кратным 0.01, и возвращает точное целое число копеек. Остальное даёт ValueError. Экспоненциальная запись допустима. Входы гарантированно имеют тип str, длину до 80 символов и модуль явно указанной экспоненты не больше 100.
