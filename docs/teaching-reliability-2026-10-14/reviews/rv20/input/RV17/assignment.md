# RV17 — тема 06/1

C1: quantity(raw) принимает исходный JSON одного математически целого числа от 1 до 1000 включительно и возвращает int. 1, 1.0 и 1e0 равнозначны. Bool, строки, массивы, null, дроби, non-finite и числа вне диапазона дают ValueError. Проверять точное исходное число до потери точности; raw имеет тип str.
