## 3. Настоящее сохранение и восстановление

Проведена одна последовательность из четырёх настоящих ответов в двух контекстах:

1. Преподаватель получил задание и исходную сдачу без готового `learning/`, провёл локальное ревью и создал записи с R1/R2.
2. В тот же контекст предъявлена частичная правка области ключа. После проверки закрыт R1, R2 сохранён открытым.
3. По сообщению «Пауза» преподаватель сам сохранил прогресс, снимки сдач, историю и свидетельства проверок внутри `learning/`.
4. Новая сессия получила только сохранённые файлы и общий профиль. Она восстановила 08/3 v1 и полный маршрут 30/92, запросила правку R2, сохранила R1 закрытым и не приписала себе исторические запуски.

Все 16 файлов входа новой сессии совпали с сохранёнными байт в байт. После продолжения изменён только PROGRESS в выходной копии learning. [Пять критериев подтверждены](roundtrip/assessment.json); [ответ новой сессии](roundtrip/resumed/output/answer.json), [состояние на паузе](roundtrip/paused/learning/PROGRESS.md), [план сообщений](roundtrip-plan.json).

В отличие от RS, исходное состояние здесь написал сам преподаватель в предыдущих ходах. Сохранённые ревью являются частью учебных файлов; история сообщений через API между контекстами не передавалась. Случаи повреждённых файлов, отсутствующей сдачи и смены маршрута этим одним опытом не покрыты.

## Воспроизведение и ограничения

```sh
python3 docs/teaching-reliability-2026-10-14/reproduce.py
```

Скрипт использует замороженные оценщики, проверяет привязку к входам и ID контекстов, пересчитывает структурные результаты и проверяет целостность внешних смысловых оценок. Он не генерирует ответы и не доказывает истинность смысловой оценки автоматически. [Команда и код завершения](reproduction-command.json), [финальная проверка файлов и тестов](verification.json), [SHA256 артефактов](manifest.json).

Все контексты запускались с `fork_turns=none`, без переопределения модели. Точная версия модели средой не закреплена; в методах сохранены доступные обозначения и фактические строки среды. Файловая система общая, ограничения чтения задавались инструкциями, а не отдельной файловой песочницей. Технические ошибки сериализации до первой успешной записи отражены в методах; исправления по результатам score не выполнялись. По три ответа на неизменных входах показывают наблюдаемую воспроизводимость, но не надёжность всех будущих диалогов или перенос на новые формулировки. Человеческий пилот и задания TR с реальным учеником в эти пункты не входили.
